# Callaghan's English Soccer Camps — website

Static redesign of the callaghansoccer.com homepage. Plain HTML/CSS, no build step.

- `index.html` — the homepage
- `assets/img/` — logo, camp photos and stock photos

## Hosting
Served with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
